# PowerSeed

광고대행사용 인플루언서 시딩 CRM.
흐름: 해시태그 수집 → 컨택(인스타 DM · Gmail) → 설문(구글 폼) → 응답을 캠페인 시트에 자동으로 옮겨 적기 → 진행 트래킹 → 원고료 지급 → 최종 시트를 엑셀/CSV로 고객사 전달

- **설문은 구글 폼**으로 만듭니다. 질문 추가·수정은 구글 폼에서 하고, 플랫폼은 질문과 응답을 가져와 캠페인 시트에 옮겨 적습니다.
- 사내에서는 플랫폼 안의 **캠페인 시트**로 관리합니다. 고객사에는 시트에서 내려받은 **최종본 파일(엑셀/CSV)**을 전달합니다.
- 인플루언서 연락은 **인스타 DM(Meta API 직접 연동)**과 **Gmail 발송**으로 합니다.

전체 설계와 단계별 계획은 [docs/ROADMAP.md](docs/ROADMAP.md), **이어서 할 일과 작업 시작 명령은 [docs/NEXT.md](docs/NEXT.md)**를 참고하세요.

## 로컬 실행 (새 기기에서 처음 받을 때)

```bash
git clone git@github.com:oh-gyuchae/powerseed.git
cd powerseed

python -m venv .venv
# Windows:  .venv\Scripts\activate      macOS/Linux:  source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env            # 로컬은 기본값 그대로 사용 가능 (외부 연동 키는 필요할 때 채움)

python manage.py migrate
python manage.py seed_demo      # 데모 데이터 + 관리자 계정 admin / admin + 메시지 템플릿 1개
python manage.py runserver
```

- 운영 화면: http://127.0.0.1:8000/ (admin / admin 로그인)
- 데이터 관리(Django Admin): http://127.0.0.1:8000/admin/
- 테스트: `python manage.py test` (외부 API는 모두 mock, 실제 발송 없음)

> `db.sqlite3`와 `.env`는 git에 올리지 않습니다. 기기마다 `migrate` + `seed_demo`로 새로 만듭니다.
> 이미 받은 기기에서는 `git pull` 후 `pip install -r requirements.txt` + `python manage.py migrate`를 실행하세요.

## 해시태그 수집기 연결

스크래퍼를 `collector/vendor/`에 넣고 `.env`의 `COLLECTOR_SCRAPER`에 함수 경로를 적습니다 (예: `collector.vendor.scraper.collect`).
- 함수 형식: `collect(hashtag, limit)`가 계정 dict 목록(또는 제너레이터)을 반환합니다.
- dict 키: `handle`(또는 `username`), `account_name`, `account_url`, `follower_count`
- 실패하면 `COLLECTOR_MAX_ATTEMPTS`회까지 `COLLECTOR_RETRY_DELAY`초 간격으로 다시 시도합니다.
- 현재 작업 백엔드는 즉시 실행 방식이라 수집이 끝날 때까지 화면이 기다립니다. 배포 시 worker 백엔드로 교체합니다.
- 승인 시 기존 인플루언서는 빈 칸만 채우고, 직접 입력한 값은 덮어쓰지 않습니다.

## 설문 (구글 폼 연동)

### 처음 한 번 (관리자)
1. 구글 클라우드에서 서비스 계정을 만들고 **Google Forms API**를 사용 설정합니다. JSON 키를 `secrets/google-service-account.json`에 두고 `.env`의 `GOOGLE_SERVICE_ACCOUNT_FILE`에 경로를 적습니다. `secrets/`는 git에서 제외됩니다.
2. 서비스 계정 이메일(JSON 안의 `client_email`)은 캠페인 설문 화면에도 표시됩니다.

### 캠페인마다
1. 구글 폼에서 설문을 만듭니다. **질문 추가·수정은 언제든 구글 폼에서** 하면 됩니다.
2. 구글 폼 ⋮ → 공동작업자 추가에 서비스 계정 이메일을 **편집자**로 추가합니다.
3. (권장) 단답형 질문 **"참여 코드"**를 넣습니다. 인플루언서별 링크에 코드가 미리 채워져, 응답이 해당 인플루언서에 자동으로 연결됩니다. 이 질문이 없으면 "인스타 계정" 답변으로 연결합니다.
4. 플랫폼의 캠페인 → **설문(구글 폼)** 에 폼 편집 주소(`…/forms/d/…/edit`)를 붙여넣고 연결합니다.
5. **질문·응답 가져오기**를 누릅니다. 구글 폼에서 질문을 고친 뒤에도 다시 누르면 됩니다. 운영에서는 `python manage.py sync_google_forms`를 cron 등으로 10분마다 실행하는 것을 권장합니다.

### 옮겨 적기 규칙
- 새 질문은 제목을 보고 플랫폼 칸을 자동으로 지정합니다. 예: "희망 원고료" → 희망 원고료, "방문 가능한 날짜" → 방문 가능일. 설문 화면에서 질문마다 바꿀 수 있습니다.
- 옮겨 적을 수 있는 칸: 계정 이름 · 이메일 · 팔로워 수 · 한 달 릴스 평균(본인 기입) · 참여 의사 · 방문 가능일 · 희망 원고료 · 송금 수단 · 특이사항. 한 칸에는 질문 하나만 지정할 수 있습니다.
- 그 밖의 질문은 **"추가 답변"**이 되어 캠페인 시트에 열로 붙습니다. "고객사 파일" 체크를 끄면 고객사 전달용 파일에서는 빠집니다.
- 자유 입력 답변도 최대한 읽어 냅니다.
  - 금액: `15만원`, `120,000`, `12k`
  - 날짜: `12/3`, `12월 5일`
  - 참여 의사: `참여할게요`, `어려워요`
  - 송금 수단: `계좌이체`, `세금계산서`
  - 읽지 못한 값은 기존 값을 덮어쓰지 않습니다.
- 응답이 들어오면 컨택 대상 · 컨택 완료 · 설문 발송 단계의 건은 **설문 응답** 단계로 옮겨집니다. 이미 더 진행된 건과 종료된 건은 단계를 바꾸지 않습니다.
- 응답자가 구글 폼에서 답을 고치면 다음 동기화 때 다시 반영됩니다.
- 매핑을 바꾼 뒤 "저장 후 전체 다시 반영"을 누르면 저장된 응답을 다시 옮겨 적습니다. 이때 시트에서 직접 고친 값이 덮어써질 수 있습니다.
- 자동으로 연결되지 않은 응답은 설문 화면에서 캠페인 인플루언서를 골라 연결하거나, 응답자 계정으로 새로 추가할 수 있습니다.

## 메시지 (인스타 DM · Gmail)

참여 상세 화면 오른쪽 **메시지 보내기**에서 채널을 고르고, 템플릿을 선택해 내용을 다듬은 뒤 보냅니다.
- 템플릿은 Admin → 메시지 템플릿에서 관리합니다. 쓸 수 있는 변수: `{{이름}}` `{{계정}}` `{{캠페인}}` `{{방문장소}}` `{{설문링크}}`
- `{{설문링크}}`는 그 인플루언서 전용 구글 폼 링크(참여 코드 미리 채움)로 바뀝니다.
- 설문 링크가 든 메시지를 보내면 컨택 대상 · 컨택 완료 단계의 건은 **설문 발송** 단계로 옮겨집니다.
- 보낸 메시지(실패 포함)와 받은 인스타 DM은 모두 메시지 이력에 남습니다.

### 인스타그램 DM (Meta API 직접 연동)
- **Meta 정책상 먼저 DM을 보낼 수 없습니다.** 첫 콜드 DM은 인스타 앱에서 직접 보내고, 상대가 답장한 뒤 **24시간 안에만** 플랫폼에서 보낼 수 있습니다. 화면에 보낼 수 없는 이유가 표시됩니다.
- 앱에서 직접 보낸 DM도 웹훅 에코로 메시지 이력에 기록됩니다.
- DM 상대는 인스타 계정명으로 인플루언서와 자동 연결됩니다. 연결되지 않은 대화는 Admin → 인스타 DM 대화에서 인플루언서를 지정하면 지난 메시지까지 함께 연결됩니다.
- 준비물:
  - Meta 개발자 앱 (Instagram API with Instagram Login)
  - 인스타 **비즈니스/크리에이터 계정**
  - 앱 검수(`instagram_business_manage_messages` 권한)
  - 공개 HTTPS 주소. 웹훅 콜백은 `https://<도메인>/hooks/instagram/`, 검증 토큰은 `.env`의 `META_WEBHOOK_VERIFY_TOKEN`, 구독 필드는 `messages`와 `message_echoes`
  - `.env` 항목: `INSTAGRAM_ACCESS_TOKEN`, `INSTAGRAM_ACCOUNT_ID`, `META_APP_SECRET`, `META_WEBHOOK_VERIFY_TOKEN`

### Gmail (발송만)
- Gmail SMTP와 **앱 비밀번호**로 보냅니다. 답장은 Gmail에서 직접 확인합니다.
- 준비물: 발송용 구글 계정의 2단계 인증 → 앱 비밀번호 생성 → `.env`의 `GMAIL_ADDRESS`, `GMAIL_APP_PASSWORD`, `GMAIL_FROM_NAME`
- 받는 주소는 인플루언서의 **이메일** 칸입니다. 계정 정보에서 직접 입력하거나, 설문의 이메일 질문으로 받습니다.
- 로컬에서 실제로 보내지 않고 확인하려면 `.env`에 `GMAIL_EMAIL_BACKEND=django.core.mail.backends.console.EmailBackend`를 넣습니다. 메일 내용이 터미널에 출력됩니다.

## 캠페인 시트 · 내보내기
- 기본 열은 `sheets/columns.py`의 `COLUMNS`에서 관리합니다. 화면 표, CSV, 엑셀이 모두 이 목록을 씁니다. 그 뒤에 캠페인별 구글 폼 "추가 답변" 열이 자동으로 붙습니다.
- `internal=True` 열은 **사내용 파일에만** 들어갑니다. 현재 사내 전용 열은 희망 원고료 · 이메일 · 설문 제출일 · 담당자 · 비고입니다.
- 엑셀 파일 형식: 헤더 고정, 자동 필터, 숫자 천 단위 구분, 날짜·시간 서식.
- CSV 파일 형식: UTF-8(BOM) 인코딩이라 엑셀에서 열어도 한글이 깨지지 않습니다.
- `=`, `+`, `-`, `@`로 시작하는 값은 수식으로 실행되지 않도록 글자로 저장합니다(수식 주입 방지).
- 시트에서 단계를 바꾸면 `change_stage()`를 거쳐 이력이 남습니다. 종료된 건의 재오픈은 참여 상세 화면에서만 할 수 있습니다.

## 진행 단계 (Participation.stage)

컨택 대상 → 컨택 완료 → 설문 발송 → 설문 응답 → 원고료 협상 → 참여 확정 → 방문 예정 → 방문 완료 → 업로드 완료 → 지급 대기 → 지급 완료
(어느 단계에서든 거절 / 중도 이탈 가능)

단계 변경은 반드시 `campaigns.services.change_stage()`를 거칩니다. 변경할 때마다 이력이 기록되고 연관 필드가 자동으로 맞춰집니다.

| 경우 | 자동 처리 |
|---|---|
| 설문 링크가 든 메시지 발송 | 컨택 대상/컨택 완료 → 설문 발송 |
| 구글 폼 응답 반영 | 컨택 대상/컨택 완료/설문 발송 → 설문 응답, 설문 제출일 기록 |
| → 참여 확정 | 참여 의사 = 참여 |
| → 거절 | 참여 의사 = 불참 |
| → 업로드 완료 | 업로드 일시 기록 (비어 있을 때) |
| → 지급 대기 / 지급 완료 | 지급 상태 변경, 지급 완료 시 지급일 기록 |
| 지급 완료 이전 단계로 되돌림 | 지급일 삭제 (지급 대기로 되돌리면 지급 상태 = 지급 대기) |
| 지급 대기 이전 단계로 되돌림 | 지급 상태 = 미지급 |
| 업로드 완료 이전 단계로 되돌림 | 업로드 일시 삭제 |
| 거절에서 재오픈 | 참여 의사 = 미응답 (참여 확정으로 바로 재오픈하면 참여) |

- 지급 완료 · 거절 · 중도 이탈은 종료 상태입니다. 다시 열려면 참여 상세 화면의 "종료된 건 재오픈"을 체크해야 합니다.
- 거절/이탈로 바꾸는 것은 되돌리기가 아니므로 업로드 일시·지급일 기록은 그대로 둡니다.

## 인플루언서 추가 규칙
- 칸반 화면 "인플루언서 추가"에 `@계정`, 계정명, 프로필 URL을 줄바꿈이나 쉼표로 구분해 여러 개 입력할 수 있습니다. 스토리 URL은 그 스토리를 올린 계정으로 인식합니다.
- 게시물·릴스 링크(`/p/`, `/reel/`)나 형식에 맞지 않는 값(영문 소문자·숫자·`.`·`_` 30자 이내가 아닌 값)이 하나라도 있으면, 해당 항목을 보여 주고 전체를 추가하지 않습니다.
- 이미 캠페인에 있는 계정은 건너뜁니다. 구글 폼 응답자를 "새로 추가하여 연결"로도 추가할 수 있습니다.

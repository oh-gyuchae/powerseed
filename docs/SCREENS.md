# 화면 구조

어떤 화면이 어디에 있고, 거기서 무엇을 하는지 한 장으로 정리했습니다. 수정 요청할 때 화면 이름을 이 문서 기준으로 쓰면 됩니다.
"Admin"은 상단 메뉴 **데이터 관리**(`/admin/`)입니다.

## 상단 메뉴

| 메뉴 | 주소 | 하는 일 |
|---|---|---|
| 대시보드 | `/` | 진행 중 캠페인을 유형별(방문형/배송형)로 묶어 단계별 인원 표시. 알림(업로드 기한 경과 등) |
| 인플루언서 DB | `/influencers/` | 전체 인플루언서 목록. 검색(핸들·ID·이름), 국가·플랫폼·카테고리·블랙리스트 필터, CSV/엑셀 내보내기. 수정은 Admin |
| 콘텐츠 성과 | `/content/` | 게시물별 7일/30일 조회·반응, 매출, 계산 열(참여율·CPV·CPM·ROAS). 캠페인 필터, 사내용/고객사용 내보내기. 수정은 Admin |
| 리포트 | `/reports/` | 국가별 섭외 → 회신 → 계약 전환율, 캠페인별 비용·성과, TOP 10 인플루언서. 유형·정렬 기준 선택 |
| 해시태그 수집 | `/collector/` | 수집 작업 목록 → 후보 검토 → 승인하면 캠페인에 추가 (수집기 자체는 보류 중) |
| 데이터 관리 | `/admin/` | 모든 데이터 직접 수정. 고객사·캠페인 생성, 환율표, 게시물·지급 내역 수정 |

## 캠페인 안의 화면

대시보드에서 캠페인을 누르면 들어갑니다.

| 화면 | 주소 | 하는 일 |
|---|---|---|
| 칸반 | `/campaigns/<id>/` | 단계별 카드. 카드에서 단계 변경, 담당자 필터, 인플루언서 추가(핸들 여러 개 붙여넣기). 업로드 기한 지난 카드는 빨간 테두리 |
| 시트 | `/campaigns/<id>/sheet/` | 캠페인 시트(원본). 행 단위 수정, 필터(단계·미완료만·업로드 예정일 경과만), 사내용/고객사용 엑셀·CSV 내보내기. 유형별로 열이 다름 |
| 설문(구글 폼) | `/campaigns/<id>/survey/` | 구글 폼 연결, 응답 동기화, 질문 → 시트 칸 매칭, 매칭 안 된 응답 연결 |
| 캠페인 수정 | Admin | 캠페인 이름·기간·유형 등. 인플루언서를 추가한 뒤에는 유형 변경 불가 |

## 참여 상세 (인플루언서 1명 × 캠페인 1개)

칸반 카드나 시트 행에서 들어갑니다. `/participations/<id>/`

- 기본 정보, 단계 변경, 단계 이력
- 메시지 보내기 (인스타 DM / Gmail), 발송 이력
- 배송형: 배송 정보(택배사·송장·발송일·수령일·통관 문제)
- 콘텐츠 성과: 게시물 추가 (수정은 Admin)
- 비용: 총비용 = 확정 원고료(원화만) + 제품 원가 + 배송비 (정산 탭은 2026-11-28 제거)
- 지난 협업 이력 (같은 인플루언서의 다른 캠페인)

## 자동으로 일어나는 일

| 언제 | 무엇이 |
|---|---|
| 메시지 발송 성공 | 마지막 연락일 = 오늘. 방문형은 설문 링크 발송 시 '설문 발송' 단계로 |
| 구글 폼 응답 들어옴 (cron) | 시트 칸에 옮겨 적고, 단계를 회신(배송형)·응답(방문형)으로 |
| 단계를 계약/확정으로 | 참여 의사 = 예 |
| 단계를 제품 발송/수령으로 | 발송일/수령일이 비어 있으면 오늘 |
| 단계를 되돌림 | 지나온 단계의 날짜(지급일·업로드·수령·발송)를 비움 |
| 지급 내역 저장 | 그날 환율로 원화 환산 (환율표에 없으면 비고 경고) |
| 블랙리스트 인플루언서 추가 | 거부하고 메시지 표시 |
